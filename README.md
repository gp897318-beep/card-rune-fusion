# RUNEFUSION — Elemental Fusion Card Duel

A turn-based card duel in a rune-stone circle at dawn. You are the Runeforger,
facing the Rival Runekeeper. Both sides have 30 Life — reduce the Rival to 0 first.

Four elements, each a colour + shape: **Ember 🔥** (red flame), **Tide 💧** (blue drop),
**Stone ⛰️** (brown mountain), **Gale 🌀** (green swirl).

- **FUSION:** play two cards of the same element in one turn — the second card's
  value doubles and gains a bonus (Ember burns, Tide draws, Stone blocks, Gale drains Ember).
- **ELEMENT WHEEL:** Ember beats Gale, Gale beats Stone, Stone beats Tide, Tide beats
  Ember. The Rival telegraphs the element it is gathering next turn — counter it for +3.
- Draw 2, gain 1 Ember per turn. Click a card (or keys 1–7) to play, SPACE ends turn,
  R restarts, M mutes. Title, table, victory and defeat screens included.

Play it: serve `game/` with any static server and open `index.html`.
